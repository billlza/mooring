# 《Mooring 使用约定》第 1 版

请完整读完下面的内容。同意的话，请在与运营者的 FaceTime 语音通话中说：

> 我已阅读并同意《Mooring 使用约定》第 1 版

运营者记下你确认的日期后，才会把配置文件交给你。

## 1. 免费，不转售

本服务只免费提供给运营者信任的少数朋友。运营者不收费，也不接受分摊费用或礼物。

你不得出售、出租或转让本服务，也不得用它为其他人提供服务。

## 2. 配置文件只给你一人

- 文件里有只属于你的凭据，不要转发或复制给任何人。
- 不要截图、拍照或生成二维码，也不要把文件内容或任何链接粘贴到聊天、邮件或文档里。
- 导入 CFM 后，删除文件、加密映像和聊天里的副本。凭据已保存在 CFM 的钥匙串凭据库中，不会因此丢失。
- 映像、配置文件、《使用指南》和本约定都不要经过微信、QQ（包括文件传输助手和 QQ 邮箱）、其他国内邮箱或网盘，或中国大陆 Apple ID 的 iMessage 和 iCloud（包括同步到 iCloud 的「桌面」和「文稿」文件夹），也不要转发到手机。
- 设备丢失、文件可能外泄，或者有人向你索要文件时，请尽快告诉运营者。如果文件可能已经到了别人手里，运营者会作废你的旧凭据，再给你一份新文件。
- 设备被他人拿走或检查时，请在安全的时候告诉运营者。运营者会作废你的账户，并更换服务器。

## 3. 合法使用，不用 P2P

- 不得用于违反英国法律或英国运营商使用条款的活动。
- 不得使用 BitTorrent 等 P2P 下载或分享，不得通过 25 端口直接投递邮件。服务器会拦截 25 端口，以及它能识别出的 P2P 流量。
- 服务器拒绝中国大陆的网站和 IP。访问国内网站时，请按《使用指南》打开 CFM 的“中国大陆直连”开关，国内网站就会直接连接，不经过本服务。
- 所有流量都从运营者在英国的个人手机线路出去，在运营商那里记在运营者名下。

## 4. 运营者能看到什么、保存多久

**运营者的电脑上会记录：**
- 你的名字（只供运营者自己辨认）、你的别名（一个随机编号，用于文件名）、你使用的 CFM 版本，以及运营者为你设置的流量配额和到期日（如果有）；
- 按你的用户编号（不含你的名字）统计的流量：上行和下行的字节数，按服务器、协议和时间段汇总；
- 你最近一次使用的时间；
- 你的账户状态变化（启用、暂停、作废），以及运营者为你做的操作（例如导出文件、更换凭据）及其时间；
- 你接受本约定的版本号和日期。

你的名字和别名只保存在运营者的电脑上，不会发送到服务器。

**服务器上会保存：**
- 按用户编号统计的流量明细和每月合计，以及每个编号最近一次使用的时间；
- 运营者的电脑定时发来的一份状态报告，供运营者在手机上查看。报告里有每位未作废用户的编号、账户状态、本计费周期的流量和最近一次使用的时间。新报告会覆盖旧报告。

**不会记录：**
- 你访问的网站、域名、IP 地址、DNS 查询或网址；不保存任何连接日志；
- 你的 IP 地址和设备信息；
- 运营者不检查你的流量内容。

**无法避免：**
- 你在国内使用的网络（宽带或手机运营商）能看到你的设备在什么时间连接了哪个服务器、传了多少数据，但看不到经过本服务传输的内容。
- 你连接时，服务器能看到你的 IP 地址，但不记录。
- 服务器提供商能看到你的 IP 地址、连接时间和流量大小；如果它控制了服务器，也能看到你访问的目标地址和域名，以及没有经过 HTTPS 加密的内容。
- 服务器通过 Cloudflare 的加密 DNS 服务（1.1.1.1 和 1.0.0.1）查询你访问的域名。Cloudflare 能看到这些域名和查询时间，但看到的是英国移动网络的地址，不是你的地址。
- 英国移动运营商能看到目标 IP 地址，以及大多数加密连接开头的域名（SNI），看不到你的地址，也看不到 HTTPS 加密的内容。
- 你访问的网站看到的是英国移动网络的地址。

**保存多久：**
- 运营者的电脑上：五分钟粒度的流量记录保存 7 天，按小时汇总的保存 35 天，按日和按月的合计保存 13 个月。
- 你的累计总量、最近一次使用的时间、账户状态变化和这些操作记录、你接受本约定的记录，以及你的名字和别名，在你的账户作废 13 个月后全部删除。
- 服务器上：流量明细保存 48 小时，每月合计在当月结束 7 天后删除，运营者的电脑会在此之前取回它们；你最近一次使用的时间在你的账户作废、服务器不再为你服务时删除。
- 你可以随时请运营者告诉你，运营者保存了哪些关于你的记录。退出时，你可以请运营者立即删除运营者电脑上的这些记录，不必等 13 个月；服务器上的记录按上面的期限自动删除。

## 5. 连不上或被封锁时

- 先在 CFM 里换用另一个节点：名称含 `-reality` 的和名称含 `-hy2` 的节点互为备用。
- 服务器每天北京时间凌晨 3 点到 6 点之间可能更新配置或重启，会中断几分钟。
- 所有用户共用一个月度流量上限。用尽时，服务会暂停到下一个计费周期。
- 运营者可能为你设置流量配额或到期日。配额用尽时，你的服务会暂停到下一个计费周期；到期后，服务会暂停到运营者恢复为止。
- 仍然不行的话，通过 FaceTime 语音告诉运营者：
  - 从什么时候开始；
  - 你用的是什么网络：哪家运营商，手机网络还是宽带；
  - 是否所有节点都不通。

  在微信等聊天软件里只约通话时间，不要提本服务，也不要发截图或配置文件。
- 本服务没有订阅链接。服务器被封时，运营者会按原来的方式给你一份新文件。导入新文件后，删除旧的配置文件。
- 运营者会尽力维持服务，但不保证随时可用。

## 6. 更新与退出

- 本约定更新后，你需要重新确认新版本，才能收到新的文件。
- 你可以随时退出，运营者会作废你的账户。
- 你违反本约定时，运营者可以暂停或作废你的账户。
