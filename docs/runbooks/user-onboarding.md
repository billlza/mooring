# 使用指南

这份指南帮你在 Mac 上把运营者给你的配置文件导入 CFM，并安全地使用。文中的按钮名称以 CFM 简体中文界面为准。

## 0. 你需要什么

- **电脑：** 一台使用 Apple 芯片（M1 或更新）的 Mac，系统为 macOS 15 或更新。
- **CFM：** Clash for Mac 0.5.0 或更新的 0.5 版本。“中国大陆直连”开关从 0.5.0 起才有，更早的版本不能用。
- **不支持的设备和客户端：** 手机、Windows 和其他客户端都不支持。
- **使用约定：** 你已经阅读《Mooring 使用约定》的当前版本，并在与运营者的 FaceTime 语音通话中确认同意。

## 1. 安装 CFM

1. 下载安装包 `Clash.for.Mac_0.5.0_arm64.dmg`：打开 <https://github.com/billlza/cfw-rs/releases/tag/v0.5.0>，在页面下方的 Assets 里点这个文件。下载不了时，告诉运营者，当面用隔空投送给你。
2. 双击打开 .dmg，把 Clash for Mac 拖进「应用程序」文件夹，然后推出这个安装映像。
3. 在「应用程序」里打开 Clash for Mac。第一次打开时，macOS 会提示它是从互联网下载的 App，点「打开」。CFM 经过 Apple 公证；如果 macOS 说无法验证开发者或文件已损坏，不要绕过提示，删掉它，再告诉运营者。
4. 以后更新：打开 Clash for Mac，在屏幕顶部菜单栏的「Clash for Mac」菜单里选「检查更新…」，按提示安装新版本。
5. 开启「系统代理」时，macOS 可能会请你输入本机密码；以后也可能再次询问。
6. 如果要使用「TUN 模式」：
   - 需要到「系统设置 › 通用 › 登录项与扩展」中批准 CFM 的网络扩展；批准之前，这个开关不可用。
   - 第一次打开时，macOS 还会询问是否允许 CFM 添加 VPN 配置，请选择允许。
7. 「允许局域网连接」保持关闭：打开后，同一网络里的其他设备也能使用你的代理。

## 2. 接收配置文件

- **当面：** 用隔空投送（AirDrop）接收，文件会出现在「下载」文件夹里；或者用 U 盘接收，U 盘里只有加密映像。
- **远程：** 你会收到一个加密磁盘映像（.dmg 文件）。
  - 它的口令是六个英文单词，由运营者在 FaceTime 语音通话中念给你；输入时全部用小写，单词之间各空一格。
  - 不要通过微信、QQ 或普通电话索要口令，也不要把口令写下来发给任何人。
  - 双击映像输入口令时，**不要**勾选“在我的钥匙串中记住密码”。
- **任何时候：** 映像、配置文件、本指南和《使用约定》都不要经过微信、QQ（包括文件传输助手和 QQ 邮箱）、其他国内邮箱或网盘，或中国大陆 Apple ID 的 iMessage 和 iCloud（包括同步到 iCloud 的「桌面」和「文稿」文件夹），也不要转发到手机。

## 3. 导入

1. 打开 CFM，进入「配置文件」，点「导入文件」，选择映像里或「下载」文件夹里的 .json 文件（如果运营者给的是 .yaml，就选 .yaml）。
2. 在「配置文件」页右键点按（或双指点按）新导入的配置文件，选「凭据」，应能看到全部凭据都已存入「钥匙串凭据库」。这一项需要先关闭「系统代理」和「TUN 模式」。
3. 不要用「导入链接」，也不要把文件内容粘贴进输入框。

## 4. 打开“中国大陆直连”

1. 进入「设置」→「内核」，打开「中国大陆直连」。
2. 「常规」页的「GeoIP 数据库」一行会显示“中国大陆直连”。

**为什么必须打开：** 服务器会拒绝中国大陆的网站和 IP，不打开这个开关，国内网站和应用会打不开。

**规则集下载：**
- 打开开关后，CFM 会经过代理下载中国大陆的规则集，下载完成后内核才会启动，所以这时节点必须能连通。
- 规则集按配置文件分别下载，「系统代理」和「TUN 模式」也各下载一次。换用新的配置文件，或者第一次打开「TUN 模式」时，都会重新下载。
- 如果节点暂时连不上，下载会失败，CFM 会显示错误：已经连接时，开关会保持关闭；还没连接时，连接会失败。稍后再试；急需上网时，可以先关掉「中国大陆直连」再连接，但这时国内网站打不开。
- 第一次连接要下载规则集，可能要等十几秒。网络较慢时（例如晚高峰）可能下载不完，CFM 会提示 “The engine did not finish starting in time”（启动没有按时完成）；用 TUN 模式、且是装好后第一次连接时，也可能只提示启动超时。已经下载完的规则集会保留，直接再连接一次即可；如果总是这样，换一个节点再试，或者先关掉「中国大陆直连」。
- 下载过的规则集会自动更新。

**隐私提示：**
- 打开后，网页里引用的中国大陆地址的资源（图片、统计脚本等）会从你自己的网络直接连接：对方能看到你的真实地址和时间，通常还能知道你正在看哪个网页，即使这个网页本身是经过代理打开的。
- 浏览需要严格保密的内容时，先打开「TUN 模式」，再把代理模式切到「全局」（见第 5 步）：这时所有应用的流量都经过代理，但国内网站会打不开。只开「系统代理」时，不使用系统代理的应用和浏览器的 WebRTC 仍会直接连接。用完再切回「规则」。

## 5. 连接

1. 打开「系统代理」，一般这样就够了。如果需要让所有应用都走代理，再打开「TUN 模式」。
2. 在「代理」页选择节点：先用名称含 `-reality` 的节点；连不通时，换成名称含 `-hy2` 的节点。
3. 「代理」页顶部有「全局」「规则」「直连」三个选项，连接后才能切换。确认选中的是「规则」：只有规则模式会让国内网站直连；「全局」会让所有流量都走代理，国内网站会打不开。
4. 用浏览器分别打开一个国内网站和一个国外网站，确认两者都能访问。

## 6. 删除文件

1. 推出映像。
2. 删除 .dmg 和 .json（或 .yaml）文件，并清空废纸篓。
3. 删除聊天记录里发送映像的那条消息。

凭据已保存在 CFM 的钥匙串凭据库里，不会因此丢失。

## 7. 不要分享

详见《使用约定》第 2 条：
- 文件和凭据只给你一人用；
- 不要转发、截图或生成二维码；
- 设备丢失、文件可能外泄，或者设备被他人拿走或检查时，在安全的时候尽快告诉运营者。

## 8. 连不上时

详见《使用约定》第 5 条：
- 先换另一个节点；
- 北京时间凌晨 3 点到 6 点之间可能有几分钟中断；
- 仍然不行，就通过 FaceTime 语音告诉运营者开始时间、所用网络，以及是否所有节点都不通。在微信等聊天软件里只约通话时间，不要提本服务。

如果 CFM 提示 “Global cleanup could not be proven.”（无法确认已经清理干净），说明内核没有正常关闭，重启 Mac 之前都无法再连接：重启 Mac，再连接即可。

收到新文件时，重复第 2、3、6 步，在「配置文件」中右键点按新配置文件并选「选择」，再删除旧的配置文件。
